## Prompt 2 Scope

Prompt 2 should fix H1 only: make `Version.h` or an equivalent version source reproducible for clean manual/native/CMake and ESP-IDF consumers. It should not address lifecycle, probe, sample readiness, numeric, FIFO, docs honesty, metadata, or hardware validation unless directly required by the reproducibility fix.

Suggested Prompt 2 done criteria:

- Fresh checkout with ignored/generated files removed can compile a minimal consumer including `OPT4001/OPT4001.h`.
- Root CMake/ESP-IDF consumption no longer depends on a pre-existing ignored `include/OPT4001/Version.h`.
- `scripts/generate_version.py check` remains useful and deterministic.
- CI or a local reproducibility check covers the clean-checkout path.
- No public API behavior changes are introduced.
